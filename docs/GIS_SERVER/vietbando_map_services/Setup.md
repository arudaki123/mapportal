---
title: VBDMapService Setup
---
1. Kiểm tra xem đã cài Microsoft Visual C++ Redistributable hay chưa.
2. Nếu chưa thì cài đặt bản mới.
3. Click chuột phải file "installCpp.bat" chọn run as admin.
4. Nhập licence key và nhấn Enter (một hoặc nhiều lần).
5. Vào giao diện quản lý service kiểm tra "Vietbando Map Service(C++)".
